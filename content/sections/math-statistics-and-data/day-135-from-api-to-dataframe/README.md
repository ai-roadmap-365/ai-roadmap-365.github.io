# Day 135 — From API to DataFrame

The second lesson of Week 20 ("Working with Real Data"). It sits after
Day 134 (finding data: open datasets and APIs, which owns pagination,
rate limits and licence judgement) and before Day 136, which opens the
exploratory data analysis process proper.

The through-line: **JSON is a tree and a DataFrame is a rectangle, so
every ingestion is a lossy flattening — and the loss is silent.** The
lesson opens with the failure this produces: the same three-customer,
nested-orders payload flattened two different ways with one line of
`pandas.json_normalize` each, giving 3 rows and a true total of 1550.0
one way, and 6 rows with an inflated total of 2650.0 the other — an
1100.0 overcount from duplicating two customers' balances across their
orders. Neither call errors. Neither warns. The fix is one sentence:
decide what one row means before you flatten, and assert it afterwards.

Week 18 gave pandas' dtype and Copy-on-Write model (Day 120), loading and
type inference (121), the partition invariant (122), groupby
reconciliation (123), joins and `validate=` (124), cleaning (125) and
Day 126's contract-and-manifest pipeline. This day applies Day 126's
raw-then-transform discipline and boundary contracts to ingestion
specifically, and Day 121's dtype-pinning discipline to JSON's extra
wrinkle: a field absent from some records rather than merely empty.

## How this lesson is rendered

`index.mdx` provides the lesson body, and the sidecar YAML files travel
with it: the site layout renders the body at the day route, injects the
quiz from `quiz.yml`, the glossary from `glossary.yml`, and the source
list from `sources.yml`, and uses `lesson.yml` for navigation, metadata
and time estimates. Images are referenced from `index.mdx` with relative
paths into `assets/`, and their alt text must stay identical to
`visuals.yml`. All cross-links — to the lab and to neighbouring days —
are generated by the layout from central configuration; never hard-code
repository or site URLs inside content files.

`ingestion-flow.svg` is animated with CSS `@keyframes` inside the file,
so it animates wherever it is rendered as an image and prints as a
still. It carries a `@media (prefers-reduced-motion: reduce)` block that
disables every animation and restores the resting state, and the still
frame carries the whole meaning on its own. Both SVGs prefix every
class, id and keyframes name — `d135a-` in the architecture diagram,
`d135f-` in the flow diagram — because an inlined SVG's `<style>` block
is not scoped to that SVG and `url(#name)` resolves document-wide, so
two diagrams on one page would otherwise restyle each other.

## Editing rules

- Every file must ship complete: no stub text, no unfinished sections, no
  filler — if a fact or figure is not verified, leave it out rather than
  approximating it.
- Every output shown in this lesson is captured from a real run on the
  authoring machine on 2026-08-20, using Python 3.14.0, pandas 3.0.5 and
  pytest 9.1.1 in this repository's authoring virtual environment. If you
  change a number here, re-run the capture and change it in the lab's
  `expected-output/` directory too.
- **The grain-trap numbers (1550.0, 2650.0, 1100.0) are load-bearing.**
  They are quoted in the opening, in "How it works", in the diagram's
  alt text, and in the lab's `expected-output/FIELDS.md`. If the example
  payload in `starter/00_brief.md` or the lab's fixtures ever changes,
  re-derive every one of these numbers and update all four places
  together.
- **pydantic and `pandas.read_json`'s "too blunt" verdict are both
  measured, not received wisdom.** pydantic was not installed in the
  authoring environment and no pydantic code was run for this lesson or
  lab — say so plainly if you touch that section. `read_json`'s behaviour
  on a nested payload (leaving `orders` as raw Python lists, no error) was
  run directly on pandas 3.0.5; re-run before changing that claim.
- **The explode-vs-record_path contrast is the lesson's second-most
  important fact after the grain trap.** `explode` keeps a row with `NaN`
  for an empty list; `record_path` drops the record entirely. Both
  behaviours were measured directly on pandas 3.0.5 in this lesson's lab
  and must not be described as "the same" or softened into "similar."
- Cite only sources listed in `sources.yml`; do not add URLs elsewhere in
  the content.

  `lesson.yml` to the revision date.
- Keep image alt text in `index.mdx` and `visuals.yml` identical, and keep
  the exact H2 heading strings intact — the lesson validator checks them.
  Alt text must contain no square brackets: a closing bracket ends
  markdown image syntax and the alt renders broken.
- If you edit either SVG, keep every class, id and keyframes name behind
  its file's prefix (`d135a-` or `d135f-`), keep the
  `prefers-reduced-motion` block, and re-check with `xmllint --noout`.
