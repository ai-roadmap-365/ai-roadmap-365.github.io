# Day 128 — Matplotlib Fundamentals

The second lesson of Week 19 ("Data Visualization"), directly after
Day 127's chart-choice framework. Week 19 closes in an Exploratory
Analysis Report on Day 133; today builds the one tool every chart in the
rest of this section, and this course, gets drawn through.

The organising sentence, returned to throughout:

> **Always `fig, ax = plt.subplots()`, always call methods on `ax`.**

## The opening failure

A plotting helper built from `plt.plot`, `plt.xlabel` and `plt.title`
draws into whichever figure happens to be "current." Called twice, with
nothing in between asking for a new figure, both calls land on the same
one — measured directly, `plt.get_fignums()` reports `[1]`, one figure,
holding two lines nobody meant to overlay. The object-API version of the
same helper, built from `fig, ax = plt.subplots()`, produces two
independent figures every time, guaranteed by construction: measured,
`plt.get_fignums()` reports `[1, 2]`, one line on each.

## What the lesson covers, each with a measured number

- The Figure/Axes/Artist object model, and why a chart is a data
  structure that happens to render as a picture — `ax.get_xlabel()`,
  `ax.lines[0].get_xydata()` and friends read it back exactly.
- `savefig`'s pixel arithmetic, checked against real PNG headers:
  `(6, 4)` inches at `100` dpi saves `600 x 400`; at `200` dpi,
  `1200 x 800`, exactly double.
- `plt.subplots(2, 3)` returning a genuinely independent `(2, 3)` array
  of Axes — a label on one cell leaves every other cell's label empty.
- `set_yscale('log')` on data containing a zero: no error, and — measured
  on matplotlib 3.11.1 — no warning either, for a mixed-sign series. The
  rendered `ylim` silently narrows to `(0.87, 18.4)`, excluding the zero
  point from view while the underlying data (`ax.lines[0].get_xydata()`)
  stays untouched.
- The label-then-legend pattern, verified directly:
  `legend.get_texts()` reads back `['measured', 'predicted']`, in
  plotting order.
- The figure lifecycle: 22 unclosed figures leave `plt.get_fignums()`
  reporting all 22 open and trigger matplotlib's own real
  `RuntimeWarning` containing `"More than 20 figures"`; `plt.close('all')`
  empties the registry to `[]`.
- Vector versus raster, made testable: `"depth (m)"` found as literal
  text inside a saved SVG, and not found anywhere in the same chart's
  saved PNG bytes.
- Testing a chart by asserting on its artists — never by diffing
  rendered pixels against a stored reference image.

## How this lesson is rendered

`index.mdx` provides the lesson body, and the sidecar YAML files travel
with it: the site layout renders the body at the day route, injects the
quiz from `quiz.yml`, the glossary from `glossary.yml`, and the source
list from `sources.yml`, and uses `lesson.yml` for navigation, metadata
and time estimates. Images are referenced from `index.mdx` with relative
paths into `assets/`, and their alt text stays identical to `visuals.yml`.
All cross-links — to the lab and to neighbouring days — are generated by
the layout from central configuration; never hard-code repository or site
URLs inside content files.

`two-apis-flow.svg` is animated with CSS `@keyframes` inside the file, so
it animates wherever it is rendered as an image and prints as a still. It
carries a `@media (prefers-reduced-motion: reduce)` block that disables
every animation and restores the resting state, and the still frame
carries the whole meaning on its own — both panels' full routing, every
label and both destination boxes, are present without motion. Both SVGs
prefix every class, id and keyframes name — `d128a-` in the architecture
diagram, `d128f-` in the flow diagram — because an inlined SVG's
`<style>` block is not scoped to that SVG and `url(#name)` resolves
document-wide, so two diagrams on one page would otherwise restyle each
other.

No LaTeX appears anywhere in `index.mdx`. Every formula and every
matplotlib call in prose is written in inline backticks or a fenced code
block, because MDX parses `{` and `}` as JSX and a `$$…$$` block broke
the site build on an earlier day.
