# Day 114 — Random Variables and Distributions

The second lesson of Week 17 ("Probability and Statistics"), directly after
Day 113's sample spaces and events. Week 17 ends in an A/B Test Analyzer on
Day 119; today builds the random-variable machinery Days 117 and 118 lean
on directly.

The organising sentence, returned to throughout:

> **A random variable is the step that turns outcomes into numbers you can
> do arithmetic on. Expectation forgives dependence unconditionally.
> Variance does not, unless the covariance vanishes.**

## The opening failure

The lesson opens with the same two-dice sample space Day 113 used, asked a
new question: how is the *sum* distributed across 2 through 12? Almost
everyone's first guess is roughly even-handed. Enumerating all 36 outcomes
shows 7 is exactly **six times** as likely as 2 or 12 — a table the reader
can verify by counting, not by trusting a claim.

## What the lesson covers, each with a worked number

- Random variable as a function `Ω → ℝ`, and the discrete/continuous split
  that forces a pmf versus a pdf.
- The pmf and the cdf as its running total, with `F(7) - F(6) == pmf(7)`
  exactly.
- The pdf trap: Uniform(0, 0.5) has density 2 — above 1 — everywhere on its
  support, and still integrates to exactly 1.
- Expectation by definition versus a 200,000-trial simulation, and the fact
  that `E[X] = 3.5` for a single die is never a value the die can show.
- **Linearity of expectation for a dependent pair** (X = first die, Y = the
  sum): `E[X+Y] == E[X]+E[Y]` exactly, with no independence assumption.
- **Variance is NOT additive** for that same pair: `Var[X+Y] !=
  Var[X]+Var[Y]`, but equals `Var[X]+Var[Y]+2*Cov(X,Y)` exactly — put
  directly beside the linearity result so the asymmetry is unmissable.
- Jensen's inequality in two lines: `E[X^2] - (E[X])^2 == Var[X]` exactly.
- `Var[aX+b] = a^2 * Var[X]`, and why the additive constant disappears.
- Seven named distributions as a working reference table — Bernoulli,
  Binomial, Geometric, Poisson, Uniform, Exponential, Normal — each with
  its situation, parameters, mean and variance.
- Poisson as the measured limit of Binomial: the maximum pmf gap shrinks
  from about 0.031 at n=10 to about 0.000027 at n=10,000, monotonically.
- Inverse-CDF sampling built from scratch, for an arbitrary discrete pmf
  and for the exponential distribution as `-ln(U)/lambda`, both compared
  against `numpy.random.Generator`'s own methods — including a
  hand-written max-gap statistic, since scipy is not installed here.

## How this lesson is rendered

`index.mdx` provides the lesson body, and the sidecar YAML files travel with
it: the site layout renders the body at the day route, injects the quiz from
`quiz.yml`, the glossary from `glossary.yml`, and the source list from
`sources.yml`, and uses `lesson.yml` for navigation, metadata and time
estimates. Images are referenced from `index.mdx` with relative paths into
`assets/`, and their alt text stays identical to `visuals.yml`. All
cross-links — to the lab and to neighbouring days — are generated by the
layout from central configuration; never hard-code repository or site URLs
inside content files.

`sampling-flow.svg` is animated with CSS `@keyframes` inside the file, so it
animates wherever it is rendered as an image and prints as a still. It
carries a `@media (prefers-reduced-motion: reduce)` block that disables
every animation and restores the resting state, and the still frame carries
the whole meaning on its own — the U value, the staircase, the sample-8
marker and all three histogram bars are present without motion. Both SVGs
prefix every class, id and keyframes name — `d114a-` in the architecture
diagram, `d114f-` in the flow diagram — because an inlined SVG's `<style>`
block is not scoped to that SVG and `url(#name)` resolves document-wide, so
two diagrams on one page would otherwise restyle each other.

No LaTeX appears anywhere in `index.mdx`. Every formula is written in a
fenced ` ```text ` block or inline backticks, because MDX parses `{` and `}`
as JSX and a `$$…$$` block broke the site build on Day 109.
