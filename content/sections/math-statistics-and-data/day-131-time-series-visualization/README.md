# Day 131 — Time Series Visualization

The fifth lesson of Week 19 ("Data Visualization"), between Day 130
(distributions and relationships) and Day 132 (visual storytelling and
chart honesty). This day covers the ways a time axis specifically gets
drawn wrong — separate from, and prerequisite to, Day 132's coverage of
deliberately deceptive scales.

The through-line: **time is not just another axis — it has structure,
and the commonest charting mistakes are the ones that throw that
structure away.** The lesson opens with a genuine fourteen-day gap in a
daily series, plotted twice: against a plain row index, where the outage
is completely invisible, and against the parsed datetime, where it shows
up as one measurably wider step among otherwise uniform one-day steps.
Every later section adds one more way that structure gets discarded:
resampling's choice of aggregation, aliasing (downsampling below a
signal's own frequency, which manufactures a specific false pattern
rather than merely losing detail), a trailing rolling window's lag
against a centred one, a missing row silently connected across instead
of shown as a gap, log-scale straightness as the test for constant
growth, calendar-correct year-over-year alignment across a leap year,
and the fact that a real calendar day can contain 23 or 25 hours across
a Daylight Saving Time boundary.

## How this lesson is rendered

`index.mdx` provides the lesson body, and the sidecar YAML files travel
with it: the site layout renders the body at the day route, injects the
quiz from `quiz.yml`, the glossary from `glossary.yml`, and the source
list from `sources.yml`, and uses `lesson.yml` for navigation, metadata
and time estimates. Images are referenced from `index.mdx` with relative
paths into `assets/`, and their alt text must stay identical to
`visuals.yml`. All cross-links — to the lab and to neighbouring days —
are generated by the layout from central configuration; never hard-code
repository or site URLs inside content files.

`aliasing-flow.svg` is animated with CSS `@keyframes` inside the file,
so it animates wherever it is rendered as an image and prints as a still.
It carries a `@media (prefers-reduced-motion: reduce)` block that
disables every animation and restores the resting state, and the still
frame carries the whole meaning on its own. Both SVGs prefix every class,
id and keyframes name — `d131a-` in the architecture diagram, `d131f-`
in the flow diagram — because an inlined SVG's `<style>` block is not
scoped to that SVG and `url(#name)` resolves document-wide, so two
diagrams on one page would otherwise restyle each other.

## Editing rules

- Every file must ship complete: no stub text, no unfinished sections, no
  filler — if a fact or figure is not verified, leave it out rather than
  approximating it.
- Every output shown in this lesson is captured from a real run on the
  authoring machine on 2026-08-20, using pandas 3.0.5, matplotlib 3.11.1
  and NumPy 2.5.2 in the repository's authoring virtual environment. If
  you change a number here, re-run the capture and change it in the
  lab's `expected-output/` directory too.
- **The gapped-series and aliasing constructions are load-bearing.** The
  fourteen-day gap in the opening example, and the 4-day-true /
  5-day-sampled / 20-day-observed aliasing numbers, are quoted throughout
  the lesson body, the diagrams, and the lab. Do not change either
  construction without re-running every capture that quotes it.
- **Nothing in this lesson's captured output is sampled or
  non-reproducible**, unlike Day 129's unseeded-bootstrap exercise —
  every number here comes from a deterministic literal or closed-form
  signal, and should reproduce exactly on a re-run with the same pins.
- Cite only sources listed in `sources.yml`; do not add URLs elsewhere in
  the content.
- When you revise any file in this directory, update `last_verified` in
  `lesson.yml` to the revision date.
- Keep image alt text in `index.mdx` and `visuals.yml` identical, and keep
  the exact H2 heading strings intact — the lesson validator checks them.
  Alt text must contain no square brackets: a closing bracket ends
  markdown image syntax and the alt renders broken.
- If you edit either SVG, keep every class, id and keyframes name behind
  its file's prefix (`d131a-` or `d131f-`), keep the
  `prefers-reduced-motion` block, and re-check with `xmllint --noout`.
- No LaTeX in `index.mdx` — MDX parses `{`/`}` as JSX and a `$$…$$` block
  has broken the site build before. Every set-notation-like value in this
  lesson (x-step sets, aggregate values) is wrapped in a fenced code
  block for exactly this reason; keep any addition wrapped the same way.
- All data in every table this lesson quotes is a small invented,
  deterministic literal, stated as such. Keep any replacement equally
  obviously fictional.
