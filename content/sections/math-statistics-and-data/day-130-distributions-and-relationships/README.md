# Day 130 — Distributions and Relationships

The fourth lesson of Week 19 ("Data Visualization"), between Day 129
(seaborn's statistical plots) and Day 131 (time series visualization).
This day is the week's deep look at how to picture a single
distribution honestly and how to picture the relationship between two
variables honestly.

The through-line: **a histogram is not the data — it is one picture of
the data, and the bin width is a parameter you chose, whether you
thought about it or not.** The lesson opens with the same 500-point
bimodal sample histogrammed at 5, 20-ish and 100 bins, showing it
collapse into one hump, then reveal its real two-cluster structure under
Freedman-Diaconis, then dissolve into noise. Every later section extends
the same idea to a different picture's hidden parameter: a KDE's
bandwidth and its boundary problem on strictly positive data; a
boxplot's five-number summary, which two engineered samples in this
lesson's centerpiece share to within 0.3 units while one is unimodal and
the other bimodal; overplotting, measured directly by counting pixel
collisions among 20,000 points; and a correlation coefficient, which
this lesson's own measurement found near zero for both Pearson AND
Spearman on a strong, symmetric, deterministic quadratic relationship —
sharper than the textbook version of that demonstration.

## How this lesson is rendered

`index.mdx` provides the lesson body, and the sidecar YAML files travel
with it: the site layout renders the body at the day route, injects the
quiz from `quiz.yml`, the glossary from `glossary.yml`, and the source
list from `sources.yml`, and uses `lesson.yml` for navigation, metadata
and time estimates. Images are referenced from `index.mdx` with relative
paths into `assets/`, and their alt text must stay identical to
`visuals.yml`. All cross-links — to the lab and to neighbouring days —
are generated by the layout from central configuration; never hard-code
repository or site URLs inside content files.

`binwidth-flow.svg` is animated with CSS `@keyframes` inside the file,
so it animates wherever it is rendered as an image and prints as a still.
It carries a `@media (prefers-reduced-motion: reduce)` block that
disables every animation and restores the resting state, and the still
frame carries the whole meaning on its own. Both SVGs prefix every class,
id and keyframes name — `d130a-` in the architecture diagram, `d130f-`
in the flow diagram — because an inlined SVG's `<style>` block is not
scoped to that SVG and `url(#name)` resolves document-wide, so two
diagrams on one page would otherwise restyle each other.

## Editing rules

- Every file must ship complete: no stub text, no unfinished sections, no
  filler — if a fact or figure is not verified, leave it out rather than
  approximating it.
- Every output shown in this lesson is captured from a real run on the
  authoring machine on 2026-08-20, using seaborn 0.13.2, matplotlib
  3.11.1, pandas 3.0.5 and NumPy 2.5.2 in the repository's authoring
  virtual environment. If you change a number here, re-run the capture
  and change it in the lab's `expected-output/` directory too.
- **The matched-quartile pair (`matched_quartile_pair` in the lab's
  `data.py`) is load-bearing.** The five target values (10, 28, 40, 52,
  70) and the resulting five-number summaries and mode counts are quoted
  throughout the lesson body and the lab. Do not change the construction
  without re-running every capture that quotes it.
- **The exercise-8 Spearman finding is deliberately reported as
  measured, not smoothed over.** The lesson states plainly that Spearman
  correlation is *also* near zero on this lesson's symmetric-parabola
  sample, which is a sharper finding than the day brief originally
  expected. Do not "fix" this by changing the sample to make Spearman
  succeed instead — the honest finding is the more valuable one.
- Cite only sources listed in `sources.yml`; do not add URLs elsewhere in
  the content.
- When you revise any file in this directory, update `last_verified` in
  `lesson.yml` to the revision date.
- Keep image alt text in `index.mdx` and `visuals.yml` identical, and keep
  the exact H2 heading strings intact — the lesson validator checks them.
  Alt text must contain no square brackets: a closing bracket ends
  markdown image syntax and the alt renders broken.
- If you edit either SVG, keep every class, id and keyframes name behind
  its file's prefix (`d130a-` or `d130f-`), keep the
  `prefers-reduced-motion` block, and re-check with `xmllint --noout`.
- No LaTeX in `index.mdx` — MDX parses `{`/`}` as JSX and a `$$…$$` block
  has broken the site build before. This lesson has no LaTeX and no bare
  curly braces in prose for exactly this reason; keep any addition the
  same way, wrapped in backticks or a fenced block if it needs one.
- Every sample this lesson quotes numbers from is either a fixed
  `numpy.random.default_rng(seed)` draw or a deterministic
  piecewise-linear construction, both defined in the lab's `data.py` and
  stated as such; keep any replacement equally reproducible and equally
  clearly labelled.
