# Day 122 — Selecting and Filtering

The third lesson of Week 18 ("pandas and Data Wrangling"), building directly
on Day 120 (Series and DataFrames, index alignment, Copy-on-Write) and Day
121 (loading and inspecting data, and how missing values actually arrive).
Day 122 does not re-teach either — it assumes a reader who already knows a
mask is a Series with an index and already knows how a real column ends up
with `NaN` in it, and asks what happens once you try to filter on it.

The through-line: **a filter is a claim about which rows you kept, and the
rows you did not keep are your responsibility too.** The lesson opens with
the failure that makes it concrete: split a column with missing values into
"high performers" and "everyone else" using two ordinary comparisons, and
the two groups do not add up to the total. Rows where the value is missing
fail both comparisons and vanish from both halves, with no exception raised
anywhere. Every section after that builds on the same habit — check that
your filters partition, and check it explicitly, every time.

## How this lesson is rendered

`index.mdx` provides the lesson body, and the sidecar YAML files travel with
it: the site layout renders the body at the day route, injects the quiz from
`quiz.yml`, the glossary from `glossary.yml`, and the source list from
`sources.yml`, and uses `lesson.yml` for navigation, metadata and time
estimates. Images are referenced from `index.mdx` with relative paths into
`assets/`, and their alt text must stay identical to `visuals.yml`. All
cross-links — to the lab and to neighbouring days — are generated by the
layout from central configuration; never hard-code repository or site URLs
inside content files.

`filter-flow.svg` is animated with CSS `@keyframes` inside the file, so it
animates wherever it is rendered as an image and prints as a still. It
carries a `@media (prefers-reduced-motion: reduce)` block that disables
every animation and restores the resting state, and the still frame carries
the whole meaning on its own. Both SVGs prefix every class, id and
keyframes name — `d122a-` in the architecture diagram, `d122f-` in the flow
diagram — because an inlined SVG's `<style>` block is not scoped to that
SVG and `url(#name)` resolves document-wide, so two diagrams on one page
would otherwise restyle each other.

## Editing rules

- Every file must ship complete: no stub text, no unfinished sections, no
  filler — if a fact or figure is not verified, leave it out rather than
  approximating it.
- Every output shown in this lesson is captured from a real run on the
  authoring machine on 2026-08-19, using pandas 3.0.5, pyarrow 25.0.1 and
  NumPy 2.5.2 in the lab's own `.venv`. The captures live in the lab's
  `expected-output/` directory; if you change a number here, re-run the lab
  and change it there too.
- **The `.str.contains()` missing-value behaviour is dtype-specific, not
  merely version-specific, and both matter.** On pandas 3.0.5's default
  `str` dtype for a plain list of Python strings, `.str.contains()` on a
  missing entry already returns a clean `False`. On the legacy `object`
  dtype — still common — it returns `None`, and filtering with that mask
  raises `ValueError`. State the dtype beside every captured value that
  depends on it, per `expected-output/FIELDS.md` in the lab.
- matplotlib, scipy and polars are not installed in the authoring
  environment. polars is described from its public documentation as a
  design contrast (`pl.col('a') > 1` composes inside one expression rather
  than through Python operator precedence, removing this lesson's
  precedence trap by construction); say so plainly and do not attribute any
  output to it.
- Cite only sources listed in `sources.yml`; do not add URLs elsewhere in
  the content. No `github.com` or `localhost` URLs anywhere.
- When you revise any file in this directory, update `last_verified` in
  `lesson.yml` to the revision date.
- Keep image alt text in `index.mdx` and `visuals.yml` identical, and keep
  the exact H2 heading strings intact — the lesson validator checks them.
  Alt text must contain no square brackets: a closing bracket ends markdown
  image syntax and the alt renders broken.
- If you edit either SVG, keep every class, id and keyframes name behind its
  file's prefix (`d122a-` or `d122f-`), keep the `prefers-reduced-motion`
  block, and re-check with `xmllint --noout`.
- No LaTeX (`$$...$$`) anywhere in `index.mdx` — MDX parses `{`/`}` as JSX
  and it has broken the site build before (Day 109).
