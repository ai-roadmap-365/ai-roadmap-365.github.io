# Day 003 — Memory Hierarchy: Registers, RAM, and Storage

The third lesson of the computing-foundations section. It walks the full memory pyramid — registers, L1/L2/L3 caches, RAM, SSD/HDD, and network storage — with approximate sizes and latencies at every level, explains why the speed/size/cost trade-off and locality of reference make the hierarchy work, introduces caching as the recurring idea in computing and virtual memory and swapping in plain language, and connects it all to model deployment: fitting weights in fast memory, memory-bandwidth ceilings, quantization, and unified memory.
