# Day 065 — CSV and JSON in the Real World

The second lesson of Week 10 ("Files, Errors, and Object-Oriented Python").
Day 64 moved bytes in and out of files safely; this lesson gives those bytes
an agreed structure. It covers the RFC 4180 quoting rules and the real-world
violations you will meet (embedded commas, quoted newlines, doubled quotes,
byte-order marks, ragged rows), the csv module done properly, the JSON data
model and exactly what a round trip changes, JSON Lines and why training data
uses it, and it closes by building the quoting state machine from scratch and
proving it agrees with the standard library.

## How this lesson is rendered

`index.mdx` provides the lesson body, and the sidecar YAML files travel with
it: the site layout renders the body at the day route, injects the quiz from
`quiz.yml`, the glossary from `glossary.yml`, and the source list from
`sources.yml`, and uses `lesson.yml` for navigation, metadata, and time
estimates. Images are referenced from `index.mdx` with relative paths into
`assets/`, and their alt text must stay in sync with `visuals.yml`. All
cross-links (to the lab, to neighboring days) are generated by the layout
from central configuration — never hard-code repository or site URLs inside
content files.

## Editing rules

- Every file must ship complete: no stub text, no unfinished sections, no filler of any kind — if a fact or figure is not verified, leave it out rather than approximating it.
- Every parsed output, byte count, and field listing quoted in this lesson comes from a real run of the lab's `examples/wrangle.py` and `examples/csv_field_parser.py` against `data/messy_orders.csv`. If you change the sample data, re-run both and update the figures here rather than leaving stale ones in place.
- Cite only sources listed in `sources.yml`; do not add URLs elsewhere in the content.
- When you revise any file in this directory, update `last_verified` in `lesson.yml` to the revision date.
- Keep image alt text in `index.mdx` and `visuals.yml` identical, and keep the exact H2 heading strings intact — the lesson validator checks them.
- Regenerate any downstream exports (search index, print/PDF builds) after edits so rendered outputs match the source.
