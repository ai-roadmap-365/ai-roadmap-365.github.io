# Day 069 — Dataclasses and Type Hints

The sixth lesson of Week 10 ("Files, Errors, and Object-Oriented Python").
Days 67 and 68 had you write record classes by hand, including `__init__`,
`__repr__` and `__eq__`; this lesson deletes that work. It covers `@dataclass`
as code generation you can inspect rather than magic, the parameters that
matter (`frozen`, `order`, `slots`, `kw_only`, `eq`, `repr`), `field()` and the
mutable default trap in both its silent and its loud form, `__post_init__` for
validation and derived fields, and `asdict`/`astuple`/`replace` as the clean
way to round-trip the CSV and JSON work of Day 65. It then treats type hints
properly — the syntax tour, and the precise reason annotations are stored but
never enforced — and closes by rebuilding `@dataclass` from `__annotations__`
in about forty lines.
