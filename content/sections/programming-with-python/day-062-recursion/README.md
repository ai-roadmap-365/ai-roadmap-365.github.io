# Day 062 — Recursion

Week 9 ("Functions and Program Design"). Having learned functions on Day 57,
the learner now meets a function that calls itself. The lesson teaches
recursion practically: the base case and recursive case, how the call stack
holds frames and where RecursionError comes from, worked examples building
intuition (factorial, recursive list sum, flattening a nested list, walking a
nested tree), tree recursion via Fibonacci and why the naive version is
exponential, memoization with functools.lru_cache to fix it, and honest
guidance on recursion vs iteration (Python has no tail-call optimization).

## How this lesson is rendered

`index.mdx` provides the lesson body, and the sidecar YAML files travel with
it: the site layout renders the body at the day route, injects the quiz from
`quiz.yml`, the glossary from `glossary.yml`, and the source list from
`sources.yml`, and uses `lesson.yml` for navigation, metadata, and time
estimates. Images are referenced from `index.mdx` with relative paths into
`assets/`, and their alt text must stay in sync with `visuals.yml`. All
cross-links (to the lab, to neighboring days) are generated by the layout
from central configuration — never hard-code repository or site URLs inside
content files.
