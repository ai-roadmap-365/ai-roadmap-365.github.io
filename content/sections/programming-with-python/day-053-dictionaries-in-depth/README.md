# Day 053 — Dictionaries in Depth

A Week 8 lesson in the "Python Basics" subsection. It teaches Python's most
important collection type — the dictionary — thoroughly: key-value mapping,
which objects can be keys and why, the safe access patterns, the counting
and grouping idioms, dict comprehensions, nested records, the insertion-order
guarantee, and the hash table that makes lookup average O(1). It ties every
idea to AI practice, where config objects, JSON payloads, feature records,
token-to-id vocabularies, and word counts are all dictionaries.

## How this lesson is rendered

`index.mdx` provides the lesson body, and the sidecar YAML files travel with it:
the site layout renders the body at the day route, injects the quiz from
`quiz.yml`, the glossary from `glossary.yml`, and the source list from
`sources.yml`, and uses `lesson.yml` for navigation, metadata, and time
estimates. Images are referenced from `index.mdx` with relative paths into
`assets/`, and their alt text must stay in sync with `visuals.yml`. All
cross-links (to the lab, to neighboring days) are generated by the layout from
central configuration — never hard-code repository or site URLs inside content
files.

## Editing rules

- Every file must ship complete: no stub text, no unfinished sections, no
  filler of any kind — if a fact or figure is not verified, leave it out rather
  than approximating it.
- Cite only sources listed in `sources.yml`; do not add URLs elsewhere in the
  content.
- When you revise any file in this directory, update `last_verified` in
  `lesson.yml` to the revision date.
- Keep image alt text in `index.mdx` and `visuals.yml` identical, and keep the
  exact H2 heading strings intact — the lesson validator checks them.
- Regenerate any downstream exports (search index, print/PDF builds) after
  edits so rendered outputs match the source.
