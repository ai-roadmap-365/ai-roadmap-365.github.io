# Day 067 — Classes and Objects

The fourth lesson of Week 10 ("Files, Errors, and Object-Oriented Python").
Days 64 to 66 moved bytes, gave them structure, and handled the errors both
produce. This lesson changes the shape of the program itself: the dictionary
plus loose functions that has been getting heavier since Day 49 becomes a
class that binds state to the behaviour maintaining its invariants. It covers
the class-versus-instance distinction, `__init__` as an initializer rather
than a constructor, `self` and the bound-method mechanism, instance versus
class attributes and the shared-mutable bug, methods against `@staticmethod`
and `@classmethod`, `__repr__` against `__str__`, encapsulation Python-style
with underscores and `@property`, an honest account of when a class is the
wrong tool, and a from-scratch object system built out of dicts and closures.
