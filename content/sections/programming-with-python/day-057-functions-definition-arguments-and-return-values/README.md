# Day 057 — Functions: Definition, Arguments, and Return Values

The first lesson of Week 9 ("Functions and Program Design"). It turns the
corner from writing top-level scripts to building programs out of named,
documented, testable functions: `def` syntax, parameters versus arguments,
positional/keyword/default arguments, return values (including returning a
tuple and the implicit `None`), docstrings, pure functions versus side
effects and why pure functions are easy to test, the mutable-default-argument
trap, and DRY. It is the foundation every later data transform, metric, and
model call in the course is built on.

## How this lesson is rendered

`index.mdx` provides the lesson body, and the sidecar YAML files travel with
it: the site layout renders the body at the day route, injects the quiz from
`quiz.yml`, the glossary from `glossary.yml`, and the source list from
`sources.yml`, and uses `lesson.yml` for navigation, metadata, and time
estimates. Images are referenced from `index.mdx` with relative paths into
`assets/`, and their alt text must stay in sync with `visuals.yml`. All
cross-links (to the lab, to neighboring days) are generated by the layout
from central configuration — never hard-code repository or site URLs inside
content files.
