# Day 068 — Inheritance, Composition, and Dunder Methods

The fifth lesson of Week 10 ("Files, Errors, and Object-Oriented Python").
Day 67 gave the reader their first classes; this lesson answers the question
that immediately follows — two classes share behaviour, so what now? It
covers inheritance and the attribute lookup that walks the MRO, what actually
breaks without `super().__init__()`, C3 linearization worked through a
four-class diamond the reader can re-derive, composition and delegation with
the same domain modelled both ways, the honest case for and against
"prefer composition over inheritance", abstract base classes against duck
typing and `typing.Protocol`, and then Python's data model as a protocol
system — closing by building a container class that unmodified builtins
accept, which is precisely the API surface of the ML libraries later in the
course.
