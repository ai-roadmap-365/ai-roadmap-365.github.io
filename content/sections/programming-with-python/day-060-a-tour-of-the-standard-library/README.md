# Day 060 — A Tour of the Standard Library

The fourth lesson of Week 9 ("Functions and Program Design"). Having built
functions (Day 57), modules and imports (Day 58), and scope (Day 59), the
learner discovers that Python ships hundreds of expertly built modules for
free — the "batteries included" standard library — and learns the judgement
to prefer them before adding a third-party dependency. The tour covers
pathlib, datetime, collections (Counter, defaultdict, namedtuple), json,
itertools, random, math/statistics, and os/sys, then teaches the
standard-library-first habit that keeps AI environments small and
reproducible before NumPy and pandas arrive in Course 03.

## How this lesson is rendered

`index.mdx` provides the lesson body, and the sidecar YAML files travel with
it: the site layout renders the body at the day route, injects the quiz from
`quiz.yml`, the glossary from `glossary.yml`, and the source list from
`sources.yml`, and uses `lesson.yml` for navigation, metadata, and time
estimates. Images are referenced from `index.mdx` with relative paths into
`assets/`, and their alt text must stay in sync with `visuals.yml`. All
cross-links (to the lab, to neighbouring days) are generated by the layout
from central configuration — never hard-code repository or site URLs inside
content files.
