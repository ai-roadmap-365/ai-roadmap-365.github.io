# Day 064 — Reading and Writing Files

The opening lesson of Week 10 ("Files, Errors, and Object-Oriented Python")
and of the "Python in Practice" subsection. It is the hinge between the
language and real work: until now every program lived and died inside one
process, and from today they can remember. The lesson covers what a file and
the cursor are, the mode strings, why `with` and an explicit `encoding` are
unconditional habits, the measured memory cost of each reading strategy, the
two buffers between a returned write and a durable byte, the atomic-write
pattern, and `pathlib` — then builds an append-only record store from scratch
that survives being interrupted mid-write.

## How this lesson is rendered

`index.mdx` provides the lesson body, and the sidecar YAML files travel with
it: the site layout renders the body at the day route, injects the quiz from
`quiz.yml`, the glossary from `glossary.yml`, and the source list from
`sources.yml`, and uses `lesson.yml` for navigation, metadata, and time
estimates. Images are referenced from `index.mdx` with relative paths into
`assets/`, and their alt text must stay in sync with `visuals.yml`. All
cross-links (to the lab, to neighboring days) are generated by the layout
from central configuration — never hard-code repository or site URLs inside
content files.
