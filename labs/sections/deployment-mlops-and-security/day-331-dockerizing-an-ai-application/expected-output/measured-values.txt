  bash tests/run_tests.sh        -> 20 passed in 0.01s

The same AI service packaged three ways:

  1. single stage, full base, weights baked in    21128 MB
  2. multi-stage, slim runtime, weights baked in  18053 MB
  3. multi-stage, slim runtime, weights mounted    4553 MB

What each change bought:

  multi-stage        21128 ->  18053 MB   3075 MB saved   1.17x
  mount the weights  18053 ->   4553 MB  13500 MB saved   3.97x
  both               21128 ->   4553 MB  16575 MB saved   4.64x

This is the number this lab exists for, and it is not the one people expect.
The multi-stage build is the optimisation every Docker tutorial teaches, and
here it is the SMALLER win by a factor of four. Moving the weights out of the
image saves 13.5 GB; removing the build toolchain and the fat base saves 3.1.

The reason is simply that most Docker guidance was written for web
applications, where the largest thing in the image is the framework. In an AI
image the largest thing is usually the model, and no amount of multi-stage
discipline touches it.

Where the size is actually felt:

  rollout to 20 nodes   16902s  ->  3642s

Four hours and 42 minutes down to one hour and one minute, for the same
service. A rollout pays the pull once per node, which is why image size is a
deployment-time property rather than a disk-space one.

One implementation note. cuda-devel (4100 MB) is BUILD and cuda-runtime
(1600 MB) is RUNTIME. Treating them as interchangeable produces either a
broken image, if you drop the runtime, or a needlessly enormous one, if you
keep the devel package. The review function relies on that distinction and so
does the whole multi-stage argument.

A second note on the test suite. An earlier version of
test_moving_the_weights_out_beats_the_multi_stage_build asserted that mounting
saves more than 3x what multi-stage saves. That failed against a fixture whose
single-stage image carried cuda-devel, where the multi-stage saving is unusually
large -- 4675 MB against 13500. The claim that actually holds is the ORDERING,
not a fixed ratio, and the test now asserts that.
