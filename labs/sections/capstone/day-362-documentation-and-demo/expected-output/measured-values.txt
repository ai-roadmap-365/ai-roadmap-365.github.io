Note the single WARN. Three provided commands are undocumented, which is a GAP
rather than a defect, so it does not fail the review. Blocking on
incompleteness makes a gate annoying enough to be switched off.

Two bugs this lab had before its own tests caught them, both in extraction:

  * untagged ``` blocks were read as commands, so the checker reported the
    document's own captured output as commands that do not exist;
  * the claimed-output pattern used re.S for the command group, so the dot
    matched newlines and the group swallowed the whole document.

Both now have dedicated tests.
