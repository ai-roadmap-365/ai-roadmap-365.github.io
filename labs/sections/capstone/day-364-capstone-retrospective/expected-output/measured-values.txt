One note on the threshold. is_uniform compares the highest area median against
the lowest, and calls the error uniform when the ratio between them is at most
1.5x. On this record that ratio is 2.909, so the check reports False -- but it
would report True at any threshold of 3.0 or above. Measured:

  spread=1.5  ->  False
  spread=2.0  ->  False
  spread=2.9  ->  False
  spread=3.0  ->  True

The threshold is a judgement rather than a law, and it is worth knowing how
close your own record sits to it. What is not a judgement is WHAT gets
compared: the areas must be compared to each other. Comparing them to the
overall median answers a different and less useful question, because the
overall median is itself pulled by whichever area contributed more tasks.
