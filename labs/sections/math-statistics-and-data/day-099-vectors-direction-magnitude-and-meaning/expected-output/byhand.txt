Distances you can check with a pen
(distance is not a separate formula: subtract, then measure)

  dist([1, 2], [4, 6])
      = |[1, 2] - [4, 6]|
      = |[-3, -4]|
      = sqrt(9 + 16) = sqrt(25)
      = 5          computed: 5.0   agrees: True

  dist([0, 0, 0], [2, 3, 6])
      = |[0, 0, 0] - [2, 3, 6]|
      = |[-2, -3, -6]|
      = sqrt(4 + 9 + 36) = sqrt(49)
      = 7          computed: 7.0   agrees: True

  dist([10, 10], [10, 10])
      = |[10, 10] - [10, 10]|
      = |[0, 0]|
      = sqrt(0 + 0) = sqrt(0)
      = 0          computed: 0.0   agrees: True

  dist([1, 1, 1], [2, 3, 3])
      = |[1, 1, 1] - [2, 3, 3]|
      = |[-1, -2, -2]|
      = sqrt(1 + 4 + 4) = sqrt(9)
      = 3          computed: 3.0   agrees: True
