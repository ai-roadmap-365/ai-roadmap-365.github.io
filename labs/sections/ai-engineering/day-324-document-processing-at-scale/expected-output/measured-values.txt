Measured on macOS 26.5.1 (Apple Silicon), Python 3.14.0, pytest 9.1.1.

  python3 examples/process_demo.py   -> 9 lines, exit 0, ~2.4s wall clock
  bash tests/run_tests.sh            -> 14 passed in 5.15s

The demo takes about 2.4 seconds because doc-06.slow deliberately exhausts its
full 2.00s budget before being terminated. The test suite passes a smaller
budget (0.3s) wherever the exact timeout value does not matter, which is why 14
tests finish in about 5 seconds rather than 17.

Scores worth noting, because each flagged document is caught by a DIFFERENT
signal:

  doc-03.scan   yield=0.02  alpha=0.81  -> flagged on yield alone
  doc-04.bin    yield=1.00  alpha=0.00  -> flagged on alphabetic ratio alone

Neither is caught by both. That is the argument for several cheap signals.
